# 석화고 취업길잡이 - 프로젝트 소개

## 프로젝트 개요

### 프로젝트명
**석화고 취업길잡이** (Career Dashboard for Seok-Hwa High School)

### 개발 목표
석화고 학생들을 위한 통합 진로 기획 플랫폼으로, 석유화학산업 채용정보, 산업 트렌드, 자격증 관리를 한 곳에서 제공합니다.

### 대상 사용자
- 석화고 학생 (공정운전과, 가스기술과 등)
- 진로를 고민하는 마이스터고 학생들
- 산업체 종사자 및 진로지도교사

---

## 핵심 기능 3가지

### 1. 📊 통합 회사정보 & 직무 검색
- **23개 주요 기업** 정보 제공 (GS칼텍스, SK에너지, 포스코에너지 등)
- 회사별 상세 정보:
  - 기업 소개 및 사업 분야
  - 인재상 (원하는 인재상)
  - 합격 가이드 (채용 팁)
  - 직원 리뷰
  - 사업 공정 설명
- 직무 필터링 (부서, 직급, 지역별)
- 즐겨찾기 및 북마크 기능
- 검색 및 상세 필터링

### 2. 🎯 AI 기반 회사 & 직무 추천 시스템
- **개인화된 추천** 알고리즘:
  - 업계 선택 (정유, 석화, 가스, 배터리, 발전, 반도체)
  - 직무 특성 선택 (연봉, 복지, 일과 삶의 균형, 안전, 성장성, 안정성)
  - 선택한 조건에 따른 점수 계산
- **매칭 알고리즘**: 회사의 특성과 학생의 선호도 비교
- **추천 순위**: 매칭 점수 기반 상위 회사 추천
- 실시간 추천 결과 업데이트

### 3. 🏆 자격증 관리 & 학습 경로
- **취득 자격증 관리**:
  - 보유 자격증 (6개): 환경기능사, 가스기능사, 공조냉동기계기능사, 화학분석기능사, 위험물산업기사, 한국사능력검정 1급
  - 예정 자격증 (5개): 산업안전산업기사, 소방설비산업기사(기계/전기), 가스산업기사, 컴퓨터활용능력 2급
- **5가지 추천 학습 경로**:
  - 안전전문가 루트
  - 가스전문가 루트
  - 설비관리 루트
  - 화학분석 루트
  - 기본 취업자격 루트
- **자격증 상세정보**: 시험 난이도, 합격률, 응시료, 관련 분야
- **진행 상황 추적**: 취득/예정 자격증 비율 시각화

## 추가 기능

### 📈 산업 트렌드 분석
- 6개 산업 분야별 상세 분석:
  - 현재 트렌드 및 전망
  - 발전 기회 및 과제
  - 핵심 기술 및 스킬 수요
  - 연봉 트렌드
  - 채용 전망
- 성장률 및 이름순 정렬

### 📝 지원 관리
- 지원한 회사/직무 추적
- 지원 상태 관리 (접수, 면접, 최종합격 등)
- 지원 이력 기록

### 👤 마이페이지
- 학생 프로필 (이름, 학과, 학년)
- 보유 자격증 현황
- 지원 이력 조회
- 관심 회사 팔로우
- 북마크 관리

## 기술 스택

- **Frontend**: React 19.0.1 + TypeScript (strict mode)
- **Build Tool**: Vite 6.4.3
- **CSS**: Tailwind CSS 4.1.14
- **UI Components**: lucide-react 0.546.0 (아이콘)
- **Type Safety**: TypeScript strict mode
- **Data Management**: mockData.ts (로컬 데이터)

---

## 프로젝트 구조

```
src/
├── components/          # React 컴포넌트
│   ├── HomeScreen.tsx           # 홈 화면 (인기 회사, 추천 직무)
│   ├── SearchScreen.tsx         # 직무 검색 화면
│   ├── RecommendationScreen.tsx # 회사/직무 추천 화면
│   ├── TrendScreen.tsx          # 산업 트렌드 분석 화면
│   ├── CertificationScreen.tsx  # 자격증 관리 화면
│   ├── MyPageScreen.tsx         # 마이페이지
│   ├── CompanyDetailScreen.tsx  # 회사 상세정보
│   ├── Header.tsx               # 헤더
│   └── BottomNavBar.tsx         # 하단 네비게이션 (6개 탭)
├── data/
│   └── mockData.ts              # 23개 회사, 직무, 트렌드, 자격증 데이터
├── types.ts                      # TypeScript 인터페이스
└── App.tsx                       # 메인 앱 컴포넌트
```
