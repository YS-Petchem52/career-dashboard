# Genspark AI 슬라이드 생성 프롬프트

## 프롬프트

다음 정보를 기반으로 전문적이고 시각적으로 매력적인 프레젠테이션 슬라이드 5장을 생성해주세요.

### 슬라이드 구성

#### 슬라이드 1: 제목 슬라이드
- **제목**: 석화고 취업길잡이
- **부제목**: AI 기반 통합 진로 기획 플랫폼
- **추가 정보**: 
  - 석화고 학생을 위한 스마트 취업 준비 도구
  - 개발: 임철현 (공정운전과 2학년)
- **디자인**: 전문적이고 신뢰감 있는 색상 (블루/그레이)
- **배경**: 석유화학 산업 이미지 또는 기술 테마

#### 슬라이드 2: 프로젝트 개요
- **제목**: 프로젝트 소개 및 목표
- **주요 내용**:
  - 개발 목표: 석화고 학생들을 위한 통합 진로 기획 플랫폼
  - 대상 사용자: 석화고 학생, 마이스터고 학생, 진로지도교사
  - 비전: 석유화학산업 진로 정보를 한 곳에서 제공
- **레이아웃**: 아이콘과 함께 3가지 요소 강조
- **색상**: 주요 색상 강조

#### 슬라이드 3: 핵심 기능 1 - 통합 회사정보 & 직무 검색
- **제목**: 📊 통합 회사정보 & 직무 검색
- **주요 기능**:
  - ✓ 23개 주요 기업 정보 제공
  - ✓ 회사별 상세 정보 (인재상, 합격가이드, 직원 리뷰, 사업공정)
  - ✓ 직무 필터링 및 검색
  - ✓ 즐겨찾기 및 북마크 기능
- **시각 요소**: 회사 로고 또는 검색 아이콘 포함
- **설명**: 한눈에 보기 쉬운 불릿 포인트로 구성
- **추가 설명**: "학생들이 관심있는 회사의 모든 정보를 한 곳에서 확인할 수 있습니다"

#### 슬라이드 4: 핵심 기능 2 & 3 - AI 추천 + 자격증 관리
- **제목**: 🎯 AI 기반 추천 & 🏆 자격증 관리
- **좌측 (AI 추천)**:
  - AI 기반 회사 & 직무 추천
  - 개인화된 추천 알고리즘
  - 업계 선택 + 직무 특성 선택
  - 매칭 점수 기반 상위 회사 추천
- **우측 (자격증 관리)**:
  - 6개 취득 자격증 관리
  - 5개 예정 자격증 추적
  - 5가지 추천 학습 경로
  - 진행 상황 시각화
- **시각 요소**: 두 개 섹션을 좌우로 분할하여 표시
- **아이콘**: 각 섹션별 대표 아이콘 사용

#### 슬라이드 5: 기술 스택 및 마무리
- **제목**: 기술 스택 & 프로젝트 특징
- **기술 스택**:
  - Frontend: React 19 + TypeScript
  - Build: Vite 6.4.3
  - CSS: Tailwind CSS 4.1.14
  - UI: lucide-react
  - 데이터: mockData.ts (로컬)
- **프로젝트 특징**:
  - ✨ 사용자 친화적 UI/UX
  - 🎨 반응형 디자인
  - 📱 모바일 최적화
  - 🔐 TypeScript 타입 안전성
  - ⚡ 고성능 (Vite)
- **마무리**: 
  - GitHub Repository 링크: github.com/YS-Petchem52/career-dashboard
  - Call to Action: "석화고 학생들의 미래 진로를 함께 설계합니다"

### 설계 지침

1. **색상 팔레트**:
   - 주요 색상: 파란색 계열 (#003d9b, #006477)
   - 보조 색상: 밝은 파란색, 화이트
   - 텍스트: 짙은 회색/검정

2. **폰트 및 텍스트**:
   - 제목: 굵고 명확한 산세리프 폰트
   - 본문: 가독성 좋은 산세리프 폰트
   - 크기: 제목은 크게, 본문은 적절히

3. **시각적 요소**:
   - 아이콘 사용하여 가독성 강화
   - 이미지 또는 다이어그램으로 복잡한 개념 설명
   - 각 슬라이드에 일관된 스타일 적용

4. **레이아웃**:
   - 깔끔하고 전문적인 레이아웃
   - 과도한 텍스트 피하기 (핵심만 표시)
   - 공백을 적절히 활용한 시각적 편안함

5. **톤**:
   - 전문성 있고 신뢰감 있는 톤
   - 학생 프로젝트이지만 수준 높은 표현
   - 진로/취업 관련 긍정적 메시지

### 추가 요청사항

- 각 슬라이드마다 한국어 제목 명확히 표시
- 핵심 수치 및 기능은 강조 처리
- 발표자 입장에서 설명하기 쉬운 구성
- 시각적으로 균형잡힌 레이아웃
- 프로페셔널하면서도 친근한 느낌
